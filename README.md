# FARHAN — Personal Website 🚀

A responsive personal portfolio website with a neon/cyberpunk look and a playable **Road Runner** mini game.

## ✨ Features

- Responsive mobile + desktop design
- Profile photo hero section
- Typewriter intro: `Hey ! This is`
- FARHAN glitch effect
- About Me section
- Road Runner mini game
- Player name input
- Keyboard controls: `A / D` or `← / →`
- Mobile swipe + touch buttons
- Pause / resume
- Increasing speed and score
- Best score saved with `localStorage`
- Game-over screen
- No external backend required
- **No music option** — removed as requested

## ▶️ Run locally

Open `index.html` in a browser.

For the smoothest local development experience, use VS Code + Live Server or any simple static web server.

## 🌐 Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders** from this project.
3. Make sure `index.html` is in the repository root.
4. Open the repository's **Settings → Pages**.
5. Under the Pages build settings, select **Deploy from a branch**.
6. Select your main branch and the `/ (root)` folder.
7. Save.
8. GitHub will provide your public Pages URL.

### Important

Keep this path exactly the same:

```text
images/farhan.png
```

If you rename or move the image, update the `<img src="...">` path in `index.html`.

## 🛠️ Customize

- Change website text → `index.html`
- Change colors/layout → `style.css`
- Change game logic → `script.js`
- Replace profile photo → `images/farhan.png`
